## 2. 바뀌지 않는 것 (중요)

- **점수는 여전히 규칙 기반이야 (D2).** OCR은 "답을 대신 골라주는" 게 아니라 **미리 채워주는 도우미**고, 최종 답은 사용자가 확인한다
- **오늘 17시 목표는 그대로야.** 진단·일정표 2개가 먼저. OCR 때문에 오늘 기능이 흔들리면 안 돼
- API 1~4번 모양은 안 바뀌어. OCR은 **5번 API를 새로 추가**하는 거야

## 3. OCR은 이렇게 동작해

```
S2 진단 준비 → [등기부 사진 올리기] (선택) → 질문 10개 (일부 답이 미리 채워짐 + "사진에서 읽음" 표시) → 금액 (채권최고액 미리 채워짐) → 결과
                 └ 건너뛰기 → 지금처럼 직접 답하기
```

| OCR이 채워주는 것 | 못 채우는 것 (사용자가 직접) |
| --- | --- |
| `T2_USAGE` 건물 용도 (표제부) | `T1_ADDRESS` 주소 일치: 계약할 집 주소와 비교해야 해서 |
| `A2_RECENT_OWNER` 최근 소유권 이전 (갑구 접수일) | `A1_OWNER` 소유자 = 집주인: 계약 상대방과 비교해야 해서 |
| `A3_TRUST` 신탁 (갑구) | `R1_VIOLATION` 위반건축물: 등기부가 아니라 건축물대장에 있어서 |
| `A4_SEIZURE` 압류·가압류·가처분·가등기·경매 (갑구) | 보증금, 매매 시세 |
| `B1_MORTGAGE` 근저당 + **채권최고액 합계** (을구) | |
| `B2_LEASE_REG` 임차권등기, `B3_JEONSE_RIGHT` 전세권 (을구) | |

- **말소된 기록(빨간 줄) 문제**: OCR은 빨간 줄을 잘 구분 못 해. 그래서 등기부를 **"말소사항 미포함"(현재 유효사항만)으로 발급**하라고 안내한다 (인터넷등기소 발급 옵션)
- 미리 채운 답에는 **"사진에서 읽음" 표시**와 근거 문장(예: "을구 1번 근저당권설정 채권최고액 금36,000,000원")을 보여준다. 근거가 약하면(`LOW`) "확인이 필요해요"로 표시
- **사진·PDF는 저장하지 않는다.** 응답에 소유자 이름 같은 개인정보를 넣지 않는다 (가린다)

## 5. OCR 엔진 후보 (BE2가 정하고 decision-log에 D9로)

| 후보 | 좋은 점 | 걸리는 점 |
| --- | --- | --- |
| AI 비전 API (Claude 등) | 사진에서 **질문 답까지 바로** 뽑을 수 있음. 표·빨간 줄 이해가 좋음 | API 키 필요, 결과를 그대로 믿으면 안 돼서 사용자 확인 필수 |
| 클라우드 OCR (네이버 CLOVA OCR 등) | 한글 인식률 좋음 | 키·신청 필요, 글자만 나와서 답 판정은 규칙으로 따로 짜야 함 |
| Tesseract (무료, 로컬) | 키 없이 바로 | 한글 등기부 인식률이 낮음 → 데모가 불안함 |

어떤 엔진이든 **API 5번 응답 모양은 같다.** 엔진이 실패하면 422 `OCR_UNREADABLE`을 돌려주고, FE는 "직접 답하기"로 넘어간다.
